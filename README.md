 Conecta Saúde
O Conecta Saúde é uma aplicação web desenvolvida com o objetivo de facilitar o acesso a informações e recursos relacionados à saúde e ao bem-estar.
O projeto foi desenvolvido como parte da disciplina de Desenvolvimento Web, tendo como referência o ODS 3 – Saúde e Bem-Estar, um dos Objetivos de Desenvolvimento Sustentável da Organização das Nações Unidas.

 Objetivo
O principal objetivo do Conecta Saúde é disponibilizar uma plataforma simples, intuitiva e responsiva, permitindo que os usuários encontrem informações e recursos relacionados à saúde de maneira organizada e acessível.

 ODS 3 – Saúde e Bem-Estar
O projeto está relacionado ao Objetivo de Desenvolvimento Sustentável 3 (ODS 3), que busca assegurar uma vida saudável e promover o bem-estar para todas as pessoas, em todas as idades.

A aplicação utiliza a tecnologia como ferramenta para contribuir com a disseminação de informações e o acesso a recursos de saúde.

 Como executar o projeto

 1. Clonar o repositório

```bash
git clone URL_DO_REPOSITORIO
```

 2. Acessar a pasta do projeto

```bash
cd conecta-saude
```

 3. Instalar as dependências

```bash
npm install
```

### 4. Executar o projeto

```bash
npm run dev
```

Depois, abra no navegador o endereço apresentado pelo Vite, normalmente:

```text
http://localhost:5173
```
 Gerar a versão para produção

Para criar a versão otimizada da aplicação:

```bash
npm run build
```

Os arquivos finais serão gerados na pasta:

```text
dist/
```
