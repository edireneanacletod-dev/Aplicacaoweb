# Conecta Saúde — Nota 2

Projeto acadêmico relacionado ao ODS 3 — Saúde e Bem-Estar.

## Tecnologias
- HTML5
- CSS3
- Bootstrap
- JavaScript
- React
- React Router
- Fetch API
- JSON
- Vite

## Executar
```bash
npm install
npm run dev
```

## Gerar produção
```bash
npm run build
npm run preview
```

## Evidências para o relatório
1. Página inicial em desktop.
2. Menu e páginas da SPA.
3. Formulário e evento de envio.
4. Tela Recursos com dados retornados pela API.
5. Código/estrutura dos componentes no VS Code.
6. Aplicação em tela de celular.
7. Repositório GitHub e aplicação publicada.
